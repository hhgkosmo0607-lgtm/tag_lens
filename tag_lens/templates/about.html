About

AI가 자동으로 정리하는
스마트 포토 갤러리

사진을 업로드하면 얼굴 검출(mediapipe)과 CLIP 제로샷 AI로 장르·주야간·실내외·동물을 자동 판별하고,
OpenCV로 시각적 특징을 분석해 여러 태그를 자동 생성합니다.

CLIP Zero-shot Genre

얼굴 검출(mediapipe + CLIP 크롭 검증) 우선, 얼굴 없으면 CLIP 제로샷 5-class(자연/도시/음식/사물/인물) 분류. 확신도가 낮으면 기타로 분류

Day/Night & Indoor

EXIF 촬영시각 우선 판별(카메라 시계 오류 자동 보정) + CLIP 제로샷 폴백으로 주야간 판별, CLIP 제로샷으로 실내/실외 판별

Animal Detection

CLIP 제로샷으로 강아지/고양이/말/동물 판별, 종(species) 로짓 gap 체크와 mediapipe 크기 게이트로 오탐 방지

Auto Tags

장르 + 주야간 + 실내외 + 동물 + 밝기 + 색온도 + 채도 + 흑백 여부를 조합해 다중 태그 자동 생성

Smart Filter

태그 AND/OR 조합 필터 + 별점 필터 + 날짜 필터 동시 지원, 선택 즉시 적용
